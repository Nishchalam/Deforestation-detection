# Legacy: EuroSAT RGB CNN benchmark (v1)

This is the v1 project: 10-class scene classification on [EuroSAT](https://github.com/phelber/eurosat) RGB (64×64 JPEGs), with all models trained from scratch. It is frozen and has nothing to do with the v2 deforestation pipeline.

The table below is generated by `python make_table.py` from `metrics/*_metrics.json`, which `evaluate.py` wrote on the held-out test split:

| Model | Test acc. | Macro P | Macro R | Macro F1 | img/s |
|---|---:|---:|---:|---:|---:|
| ResNet-18 | 96.04% | 0.960 | 0.960 | 0.959 | 276 |
| GoogLeNet | 87.00% | 0.880 | 0.869 | 0.868 | 139 |
| EfficientNet-B0 | 86.63% | 0.889 | 0.869 | 0.866 | 153 |
| AlexNet | 83.26% | 0.840 | 0.833 | 0.828 | 189 |
| LeNet-5 | 64.41% | 0.655 | 0.631 | 0.620 | 214 |

- VGG-16 did not converge (single-class collapse) and has no metrics file, so it is not listed.
- The v1 README listed LeNet-5 at 76.26%. Its metrics file says 64.41%, and the table above uses the file.
- Throughput was measured on the original training machine with batch size 32 and is not comparable across hardware.

To reproduce, put EuroSAT RGB in `legacy/eurosat/data/raw/EuroSAT/` and the split CSVs in `data/processed/` (see the v1 README in git history, commit 4c8ef0f). Then run, from this directory: `python train.py --model resnet18` and `python evaluate.py --model resnet18 --checkpoint outputs/checkpoints/resnet18/best_model.pth`.
